PostFiat Network Architecture and Agent Integration Reference

Public testnet observations (2026-11-13, 02:29–02:44 UTC) + the complete public agent work-request, submission, and verification surface of the Task Node. Every measured claim links to an unedited output in the repository; every specification-derived claim cites a primary source.

Repository: this repo. Docs: citations · methodology · topology map · consensus flow · agent integration · findings · decision memo · claim–evidence index (all as Markdown in docs/; this page is the summary).

Two networks, keep them apart. The live testnet runs postfiatd 1.0.9 (a rippled fork, XRPL-style consensus, quorum 17/25, ~3 s closes). The l1v2 design (Consensus v2 prepare/precommit QCs + Cobalt ratification) is specified in the whitepaper and the postfiatl1v2 repo — it is not what the live testnet runs today.
